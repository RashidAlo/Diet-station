DietStation Dot

The brand's dot-matrix animation, compiled into a real font family — four weights, Latin and Arabic, with full contextual shaping. Proof it below, then dial the glyphs themselves in the editor.

Specimen

Latin comes straight from the animation's typewriter grid; Arabic is traced from Avenir Next World onto the same 9-row dot grid — letters join through initial, medial and final forms, lam-alef included. Weight is dot size: heavier cuts grow the dots until they fuse into strokes. Type to proof any word across all four weights.

React Native handoff

Load the four OTFs from the family zip with expo-font and address each weight by its family name — custom faces don't map through fontWeight reliably in RN. Arabic contextual shaping (initial/medial/final forms and lam-alef) is baked into the font's OpenType tables, so native text rendering shapes it automatically — no extra work.

// npx expo install expo-font   (OTFs from the family zip -> assets/fonts/)
import { useFonts } from 'expo-font';

const [fontsLoaded] = useFonts({
  'DietStationDot-Light':   require('./assets/fonts/DietStationDot-Light.otf'),
  'DietStationDot-Regular': require('./assets/fonts/DietStationDot-Regular.otf'),
  'DietStationDot-Medium':  require('./assets/fonts/DietStationDot-Medium.otf'),
  'DietStationDot-Bold':    require('./assets/fonts/DietStationDot-Bold.otf'),
});

// Address weights by family name, NOT fontWeight:
<Text style={{ fontFamily: 'DietStationDot-Bold', fontSize: 40 }}>
  diet station
</Text>
<Text style={{ fontFamily: 'DietStationDot-Regular', fontSize: 40 }}>
  دايت ستيشن   {/* shapes natively — contextual forms are in the font */}
</Text>

// Notes:
// - Unicase: A-Z and a-z share one dot form.
// - Weights are dot radius on one grid (R49/55/62/70) — mixing weights
//   keeps perfect vertical rhythm.
// - Web embeds use the hosted WOFF2s (Copy CSS embed above).
