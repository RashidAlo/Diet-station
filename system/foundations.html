Color

An Apple-light canvas with one loud voice: brand red. Grays do the talking everywhere else, green is reserved for success and live states.

Spacing

Apple-loose, on a 2px grid. Micro gaps inside controls, 10–14 between siblings, 18–26 for card insets and stacking. One number to remember: cards breathe at 24–26px.

8chip padding, tight control gaps
10action-bar gaps, pill text padding

14bar padding, grid gaps
18card-to-card stack, action-row top margin

24standard card inset (native + flow surfaces)
26web card inset (hub + lab cards)

Radii

Soft everywhere, round where it acts. Inputs and code sit at 10–12, surfaces at 14–18, sheets and native cards at 24+, and anything tappable that isn't a card is a full pill.

Elevation

Shadows are soft, warm-neutral and always double-layered: a hairline contact shadow plus a large, heavily-offset ambient blur with negative spread. Nothing floats hard.

Colored glows are allowed only on live/status controls, tinted with the control's own color — e.g. 0 5px 14px -6px rgba(52,199,89,.55) under a green publish button.

Dev handoff

The full token sheet as CSS custom properties and a React Native object. Native devs: these map 1:1 to a SwiftUI Color + spacing extension.

:root {
  /* color */
  --ground: #F5F5F7;   /* canvas */
  --card: #FFFFFF;     /* surfaces */
  --sheet: #FBFBFC;    /* bottom sheets, sidebars */
  --ink: #1D1D1F;      /* primary text */
  --ink-soft: #6E6E73; /* secondary text */
  --ink-faint: #8E8E93;/* tertiary text */
  --glass-ink: #0B0E12;/* content on glass over light backdrops */
  --line: rgba(0,0,0,.08);      /* hairlines, draw at 0.5px */
  --control: #E9E9EC;  --control-deep: #ECECEF;
  --red: #ED1C24;      /* THE brand color in UI */
  --red-pressed: #D4141C;
  --red-soft: #FFF2F2;
  --motion-pink: #FF3848;       /* animation ball ONLY — never UI */
  --ok: #1F8A4C;  --ok-soft: #EAF6EF;  --ios-green: #34C759;

  /* radius */
  --r-control: 12px; --r-surface: 14px; --r-stage: 16px;
  --r-card: 18px; --r-sheet: 24px; --r-card-native: 24px;
  --r-launcher: 38px; --r-pill: 999px;

  /* elevation */
  --raise-control: 0 1px 2px rgba(0,0,0,.08), 0 3px 8px rgba(0,0,0,.06);

  --raise-knob: 0 3px 8px rgba(0,0,0,.15), 0 1px 1px rgba(0,0,0,.16);
}
