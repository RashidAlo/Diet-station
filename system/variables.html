Variables

The token architecture of the DietStation Design System, mapped 1:1 from the Figma file — every ramp, alias and mapped role below is read from the real variables, not retyped. Brand is the roots, alias is the trunk, mapped is the leaves.

The tree

Three color collections chained by aliases, plus three side collections. Designers and devs only ever consume the mapped layer — brand and alias exist so one change at the root re-themes everything downstream.

The DietStation twist on the classic three-tier setup: brand modes localize typography — English (Urbane + Proxima), Arabic (Avenir Next World), and a Dietstation display mode (all-Urbane) — so language is a brand-level switch, while light/dark stays a mapped-level switch and device size lives in responsive.

Brand — the roots

Every ramp runs 100→1200 with a 150 half-step (station red adds a 650 for the pressed brand red). Tap any cell to copy its hex. Note station red/600 = #ED1C24 — the brand red lives mid-ramp, not at the top.

Alias — the roles

Whole ramps get renamed to what they mean. The DietStation call: primary is grey — the interface's workhorse tone — and the brand red is secondary, kept loud by being scarce. Error borrows the rose ramp so it never clashes with brand red.

Numbers that stop at alias

Border width and radius alias the master scale and go no further — a mapped copy would just repeat them (the same simplification the setup video lands on).

border width: xs 1 · sm 2 · md 4   |   border radius: none 0 · 50…800 = 2…32 · round 1024

Mapped — the leaves

All 165 consumable tokens: surface / text / icon / border × role × state. Flip the mode and watch every chain re-resolve through alias down to the brand hex — this is exactly what the Figma file does. Tap a row to copy the resolved hex.

Responsive — type & spacing

One collection carries everything that changes with device size: a hero-to-caption type ramp (size / line height / paragraph spacing) and the layout spacing scale. Flip the mode to see the mobile cut.

Layout spacing

Fonts come from brand: heading + paragraph families and the 100–800 weight names switch per brand mode (English / Arabic / Dietstation). Composite text styles in Figma (body-md/medium, Button/button-md…) bind these to the responsive sizes.

Review notes — to work through together

Things the dump surfaced that look like accidents or open questions. Nothing here is changed on the lab side — flag what you want fixed in Figma and I'll keep this page in sync.

Two stray Arabic-mode values in brand: grey/250 is #EDEDED in English but #F2F2F2 in Arabic, and yellow/1200 is #322802 vs #332222. Ramp hexes should almost certainly be identical across brand modes — these look like accidental edits while the Arabic mode was active.
Naming typos in mapped/gradients: surface/primary/default-subtle-hover-atl (“atl” → “alt”), full gradients/defualt stop 2, border/warning/action-subtle-hover (others say “default-subtle-hover”), and icon/warning/on-default-subtle-hover (others say “on-color-subtle-hover”). Cheap to fix now, expensive after dev handoff.
Duplicate collection: “brand exported from Diet Station Design System 1.0” (119 vars, one mode) sits beside the real brand collection — looks like an import artifact worth deleting.
Both red ramps: brand has red (unused by alias) and station red (the real secondary). Keep plain red as a spare, or retire it?
neutral light blends two ramps (grey 100–800, slate 900–1200) while neutral dark is all grey — intentional warm-dark ink? It's a nice trick; worth writing down as a rule if so.
Lab ↔ Figma deltas to reconcile: the lab's Foundations page documents the shipped prototypes (ink #1D1D1F, ground #F5F5F7, iOS green #34C759), while Figma maps text to slate #0B0E12 and success to emerald #26A659.
