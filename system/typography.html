DietStation Design Lab

Typography

Four voices: Urbane Rounded speaks, Proxima Nova explains, Avenir Next World carries the Arabic experience, and DietStation Dot performs. One scale system, applied per typeface below — the numbers come straight from the Figma responsive collection.

The families

Aa
Urbane Rounded · headings & controls (EN)

Every English title, button, label and pill — the hero-to-h7 slice of the scale plus all four Button cuts. Bound in Figma as font style/heading in the English brand mode. Licensed; served from the lab, never redistributed.

Aa
Proxima Nova · body (EN)

All English running text — the paragraph-lg-to-caption-xsm slice. Bound as font style/paragraph in the English mode. Falls back to -apple-system so native devices can substitute SF.

عأ
Avenir Next World · Arabic — headings and body

The Arabic brand mode swaps both font variables to Avenir Next World — one family carries the full ramp, headings and body alike, with native shaping. The scale numbers don’t change; only the family and the cut names do (weight 500 is “demi” here), and Direction/isRTL flips the layout.

aa
DietStation Dot · brand display

The dot-matrix brand font compiled from the animation — four weights (weight is dot size), Latin + fully-shaped Arabic, unicase. Display moments only: wordmarks, splash, brand peeks. Never body text, never in the responsive ramp.

The scale, per typeface

One responsive scale from the Figma variables — hero, h1–h7, paragraph lg/md/sm, three captions, four buttons — applied to each typeface on its own slice. Pick a voice, flip desktop/mobile, and every row re-sizes with its real size / line height · paragraph spacing.

Weights

Style names map to the brand weight tokens, and the tokens resolve to a different cut name per mode — that indirection is what lets one text style re-font itself for Arabic. Note the deliberate shift: the system’s “regular” wears each family’s Light cut.

Rules of voice

Urbane never runs long. If it wraps past two lines it should have been Proxima.
Proxima never shouts. Emphasis inside body text is a color shift to ink, not a weight jump.
Arabic speaks Avenir — all of it. Headings and body share one family; hierarchy comes from the scale and the medium/demi cuts, never from mixing families. Shaping is native; direction comes from isRTL.
Dot never explains. It’s the brand performing — one or two words, display size, then hand back to Urbane (or Avenir).
The ramp is the law. Sizes, line heights and paragraph spacing come from the responsive tokens — never freehand a font size.

Dev handoff
