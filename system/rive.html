Rules & pipeline

Never recolor the dots. Ball #FF3848, icons white — the one law from Brand rules, enforced in the script itself.
Motion is authored in one place. All geometry and choreography live in generate_shapeshift.py; the Lottie JSON, data blobs and the Luau script are compiled from it. Never hand-edit an export.
Rive is the interactive cut, Lottie the linear one. State-machine placements (onboarding, quiz) embed the .riv; passive placements (marketing, previews) use the Lottie loop.
The app owns the chrome. Buttons, captions and pages are HTML/native around a transparent Rive canvas — the artboard renders dots only.

// Web — @rive-app/canvas (the lab vendors 2.41.0 at breathe/rive.js)
const r = new rive.Rive({
  src: 'https://rashidalo.github.io/Diet-station/breathe/dietstation.riv',
  canvas, autoplay: true,
  stateMachines: 'State Machine 1',
  autoBind: true,                       // REQUIRED — the SM reads the Machine VM
  onLoad: () => {
    r.resizeDrawingSurfaceToCanvas();
    const st = r.viewModelInstance.number('state');
    st.value = 1;                       // 1 weight · 2 muscle · 3 pregnancy · 4 gut
    st.on(v => syncChips(Math.round(v)));  // auto-advance writes back every ~6s
  },
});
