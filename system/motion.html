Motion

Seven named curves cover every animation in the lab. Tap a curve to replay its ball and copy the CSS. Durations are part of the token — a curve without its time isn't the token.

Easing tokens

Values are lifted verbatim from the shipping prototypes — Press appears 16× across the flows, Glide 7×, Pop 4×. When in doubt: Press for touch feedback, Sheet for anything that slides in from an edge.

Choreography patterns

How the curves combine. These are the lab's recurring moves — reuse them before inventing new ones.

Staggered pops
A row of elements fires top-down or left-right with a fixed delay step, each on the Press curve — the coupon perforation holes pop one by one at thresholds between 30 and 100% of the gesture. Every pop pairs with a haptic tick (Android vibrate(8); iOS haptics via the native shell).
step 80–100ms · each pop .3s cubic-bezier(.3,.8,.3,1)
The overlay rule (law, Rashid 2026-09-10)
A scrim never translates — it dissolves in place; only the sheet travels. Exit reverses both: sheet slides down, scrim dissolves out where it stands. Canon travel is the house spring; the hub's settings primer keeps its softer Settle variant. Native covers presenting a web surface stay transparent and non-animated so the page self-presents (reference: auth/?solo=1). The full sheet system — modes, action bar, drag-to-close — lives here.
scrim: opacity ~.32s ease, rgba(11,14,18,.45) · sheet: translateY(103%) → 0, .55s cubic-bezier(.32,.72,0,1) · primer variant .42s Settle · out .4s Exit
Tuck & return
Chrome gets out of the way during use: the mobile tab bar auto-collapses into a corner chip after ~2s of prototype use and slides back on view change — always on the Sheet curve, always fading opacity in the last third.
.45s cubic-bezier(.32,.72,0,1) + opacity .3s ease
Press everywhere
Anything tappable scales to .96–.98 on touch-down and springs back on release. It's feedback, not decoration — 150–180ms, never longer.
transform .15–.18s cubic-bezier(.3,.8,.3,1) → scale(.96)
Brand moments overshoot
Only brand/reward moments earn a bounce (Bounce or Spring) — a coupon ripping free, the splash's retro pop, a reward revealing. UI chrome never bounces.
.5–.88s cubic-bezier(.26,1.36,.42,1)

Counting numbers

When a displayed value changes, it counts over — it never jumps. The home screen's calorie and macro readouts set the standard: scroll the meal strip between days and the numbers roll to their new values. Tap a day below to feel it.

1200Kcal 55C 87P 23F
tap a day · tap fast to interrupt mid-count

The recipe

420ms, cubic ease-out (1 − (1−p)³), value rounded each frame. The count always starts from the currently displayed number, not from the previous target — so interrupting a count mid-flight continues from what the eye is actually seeing and never snaps backwards. A light haptic fires once at the trigger, not per digit.

Native gets this from the platform: .contentTransition(.numericText(value:)) under a .spring(duration: 0.55) keyed to the value's source — SwiftUI rolls the digits itself, including odometer-style per-digit travel the web tween approximates with a single interpolated value.

Count or snap

Count when the value is the same quantity moving — the same day's calories recalculated, a macro total as meals change, a countdown of remaining days. Snap when the number is a different thing entirely: a new item's price, an ID, a list index. Counting between unrelated values reads as a slot machine, not a measurement.

Sibling: the ticking countdown
The days-left dial uses a deliberately different motion — it steps down one whole unit at a time with a light haptic per tick, while its arc eases to the final fraction underneath. Discrete units that a person would count out loud tick; continuous quantities roll.
step .07s linear, 75ms between ticks · arc .9s ease-out · haptic: light impact, intensity .4, per tick

Canonical implementation: countTo(el, to) in home/index.html — one shared function driving calories and all three macros, matching native's thinPair. (It previously counted only the calories while C/P/F snapped; brought in line when this pattern was written up, so web and native now roll together.)

Dev handoff

Tokens as CSS custom properties and a Reanimated mapping. The bezier curves translate to withTiming; only brand moments use withSpring.

  --e-press:  cubic-bezier(.3,.8,.3,1);    /* touch feedback     .15–.18s */

// Counting numbers — the shipped home recipe
// Canonical web implementation: countTo() in home/index.html
// 420ms, cubic ease-out, counted FROM THE DISPLAYED VALUE
function countTo(el, to) {
  const from = +el.textContent;          // on-screen, not the last target
  if (from === to) return;
  const t0 = Date.now();
  clearInterval(el._count);              // a new count replaces the old
  el._count = setInterval(() => {
    const p = Math.min(1, (Date.now() - t0) / 420);
    el.textContent = Math.round(from + (to - from) * (1 - Math.pow(1 - p, 3)));
    if (p >= 1) clearInterval(el._count);
  }, 28);
}
// one light haptic at the trigger, never per digit:
navigator.vibrate && navigator.vibrate(8);
// CSS: font-variant-numeric: tabular-nums  (digits must not reflow while counting)
